# ДЗ2 «Практика промтинга» — BookTrack

Цель работы — научиться задавать AI проверяемые задачи через контекст, практические правила, структуру RTCF и пошаговую декомпозицию.

BookTrack — планируемое учебное веб-приложение для персонального учёта книг: список, добавление, редактирование, удаление, статусы чтения, поиск и фильтрация. На момент подготовки комплекта (15.10.2026) в репозитории обнаружены отчёт ДЗ1 и изображения; исходного кода приложения нет. ДЗ2 содержит документацию и промпты для будущей работы, а не реализацию.

## Порядок изучения

1. Прочитать контекст и проверить границы MVP и допущения.
2. Изучить правила и способ передачи их агенту.
3. Проверить пять RTCF-шаблонов и заполненные примеры.
4. Проследить семь этапов декомпозиции формы.
5. Проверить методику A/B; после реального проведения приложить ответы и заполнить оценки.
